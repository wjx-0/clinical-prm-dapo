# Data

Expected data groups:

- `raw/`: source datasets such as MedQA, MedMCQA, and CMExam.
- `processed/`: normalized QA JSONL files.
- `sft/`: instruction-style SFT JSONL files.
- `prm/`: pointwise or pairwise process reward model data.
- `rl/`: prompt-only JSONL files for GRPO/DAPO rollouts.

Keep large dataset files out of git.
