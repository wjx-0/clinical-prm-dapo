# 消融实验

本文档用于记录不同 reward 组件、训练配置和数据设置对结果的影响。

## 实验目标

验证哪些设计真正带来收益，避免只凭单次实验结论判断方案好坏。

## 待验证因素

- 答案正确性 reward
- 格式 reward
- PRM 过程 reward
- 一致性 reward
- 长度惩罚
- GRPO 与 DAPO 对比
- 不同采样数量
- 不同最大回复长度
- 不同 SFT checkpoint 初始化

## 记录格式

每个消融实验建议记录：

- 实验编号
- 基线设置
- 改动项
- 数据集与 split
- 训练配置
- 主要指标
- 结论
- 失败案例
